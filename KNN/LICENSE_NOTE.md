# Licensing note for KNN evaluation

The KNN evaluation code does not redistribute ImageNet, model checkpoints,
large extracted feature matrices, or cloned third-party repositories.

ImageNet remains subject to its own access and usage terms. Each supported
vision encoder and its checkpoint remain subject to the license of the
corresponding upstream project. The externally stored feature artifacts must
also be used according to their source dataset and model licenses.

Review all applicable upstream licenses and access terms before downloading,
running, publishing, or redistributing any KNN evaluation component.
